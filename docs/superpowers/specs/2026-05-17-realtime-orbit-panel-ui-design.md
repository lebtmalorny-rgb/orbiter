# Улучшение real-time орбиты и панелей

## Цель

Убрать визуальное ощущение нескольких расходящихся витков в real-time режиме и
сделать информационные панели менее навязчивыми, не меняя источник данных SGP4.

## Решение

1. Real-time траектория продолжает загружаться полным окном вокруг текущего UTC,
   но линия орбиты в сцене показывает только текущий виток вокруг курсора UTC.
   Длина витка берется из `element_parameters.period_min`, если она есть; иначе
   используется безопасный fallback для LEO. Это не меняет расчёт и не скрывает
   данные на сервере, а только ограничивает видимый участок линии.
2. Опция `Поверх Земли` выключена по умолчанию. При выключенной опции линии
   подчиняются depth test и не просвечивают через сферу Земли.
3. NORAD/OMM-панель остается доступной, но по умолчанию скрыта и получает
   отдельный переключатель `OMM` в сценовой панели управления. Если он выключен,
   подробная панель скрывается, а компактный HUD с UTC, высотой и скоростью
   остается.

## Границы

- Frame/time/units/force model real-time режима остаются прежними:
  Skyfield/SGP4, UTC wall-clock, км и км/с, GP/OMM mean elements.
- RK4-пресеты не приводятся к SGP4 и не должны визуально совпадать с real-time
  траекторией без общего начального состояния и force model.
- Полноценная WGS84/ITRF ground-track архитектура не входит в это изменение.
